# REG-19: the replication (whole-window test)

*Registered 2026-11-11 · GPU runs · claim P0, C1 · result 2026-11-13*

| | |
|---|---|
| **Question** | At λ = 2.0, does REG-14's 180 s burst leave the server stuck, cold and below its load for a 3000 s watch without the line ever emptying, while the same schedule without the burst stays healthy, in most of seeds 15–19? A new per-seed test, written after REG-18's data and judged only on new seeds. |
| **Runs** | Five same-seed pairs, seeds 15–19, λ = 2.0, closed-loop turns, arrivals to 4080 s, 3000 s watch (`configs/stage2_control_l1pl350cl_r2.0_w3000_s<s>.yaml`, `configs/burst_l1pl350cl_r2.0_w3000_s<s>.yaml`), control first, order 15–19, REG-18's futility stop. All ten runs valid and counted; all five seeds run. |
| **Outcome rule** | Per seed `gate.reg19_seed_outcome` (REG-18's rules with a new test): with the burst `stuck` at 4080 s and the control `recovered`, the seed is `emptied_retipped`, `emptied_cold` or `emptied_unclear` if the line emptied (0 waiting for 30 s) in the watch; `inconclusive` if W's c or λp is NaN; `stuck_not_cold` unless over W = [600, 3000) s after the burst's end the completion rate is below min(2.0, W's λp); `pass_clear` if the control waited in ≤ 0.5 of the scrapes of each of W's eight spans, else `pass_warm_edge`. Matrix `gate.reg19_outcome` = REG-18's: `supports` if k_clear ≥ 3, `supports_edge` if k ≥ 3, `some` if k = 1–2, `none` if k = 0, after the surge and control checks. |
| **Prediction** | Per seed: burst-run baseline pf ≥ 0.98 ≈ 0.85; control `recovered` ≈ 0.9; burst `stuck` without the line emptying ≈ 0.75 (seed 18 ≈ 0.5); cold side given that ≈ 0.95; P(pass) ≈ 0.55 (seed 18 ≈ 0.36). E[k] ≈ 2.5, P(k = 0) ≈ 0.03, P(k = 1–2) ≈ 0.46, P(k ≥ 3) ≈ 0.52; k_18 likely 0–2; P(`surge_reading_wrong`) ≈ 0.23. |
| **Decision under each outcome** | Wording fixed for any pass, naming the new test and k_18. `supports`: draft C1's confirmation at λ = 2.0 (4500 s watch, a drop to λ = 1 long enough for the line to empty, the return) on a seed chosen by a rule fixed beforehand. `supports_edge`: the author decides. `some`/`none`/stop: if `drains` in 2 or more seeds, report the zone as too narrow at L1; otherwise the author chooses between λ = 2.1 and that report. `controls_not_healthy`: the author decides. `surge_reading_wrong`: stop and rethink. |
| **Adversarial review** | Two rounds. Round 1: three should-fix items (T1: an emptied line read as a drain; T2: the comparison with REG-18's rule was not REG-18's rule; T3: run order confounded with treatment) and seven minor items; round 2: two should-fix items (R2-T1, R2-T2) and four minor items. All were applied before the runs; no third round. |
| **Result** | `supports`, 5 of 5 (k_clear 5; one-sided 95 % Clopper–Pearson upper bound 1.000, lower bound 0.549); all controls `recovered`, no emptying, W's c 1.740–1.758 against λp 1.923–2.077, `order_flag` False in all five. Under REG-18's per-span test on the same runs (k_18): 3 of 5 (seeds 15 and 18 `stuck_draining`). |
| **Prediction held** | yes (likeliest outcome; P(k ≥ 3) ≈ 0.52); k = 5 itself had ≈ 0.033 (DERIVED in the result), and k_18 0–2 was missed (3) |
| **Not separated** | A state that holds only while the load stays at 2.0 against one that also outlasts a lower load (only C1's confirmation with its drop separates them); whether REG-18's 1 of 4 and these 3 of 5 differ by seed or by chance. |
