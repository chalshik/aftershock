# REG-20: the turn-release test

*Registered 2026-11-12 · GPU runs · claim K1 · result 2026-11-16*

| | |
|---|---|
| **Question** | K1: with open-loop turns a session's next turn arrives while its previous turn still runs, so its prefix is held and cannot be evicted, and the stuck state does not hold; with closed-loop turns it can. Do REG-19's burst runs with open-loop turns, on the same seeds, recover where the closed-loop runs stayed cold and backlogged? Arm B checks the same at λ = 2.5, the same share of the open-loop warm capacity. |
| **Runs** | Arm A: 5 open-loop burst runs at λ = 2.0, seeds 15–19 (`configs/burst_l1pl350ol_r2.0_w3000_s<s>.yaml`, only `closed_loop: false` changed), paired with REG-19's 5 closed-loop burst runs, plus a drift rerun of REG-19's seed-15 closed run. Arm B: 3 open-loop burst runs at λ = 2.5, seeds 15–17. Conditional open-loop controls: none due. Arm A ran only after the gate `k1.a_may_start` passed (best p 0.031). |
| **Outcome rule** | Readout `k1.cold_backlogged`, end window [3480, 4080) s against baseline [300, 900) s: reuse of later turns ≤ base − 0.06, mean waiting > base + 1.0, mean KV ≥ 0.9; recovered = reuse ≥ base − 0.06 and waiting ≤ base + 1.0; otherwise `partial_open`. `k1.k1_outcome`, in order: `too_few` (< 2 seeds), `pending_controls`, `open_arm_overload`, `closed_not_cold`, `refutes` (`stuck_open` + `lost_open` + `cold_control` ≥ 3), `supports` (exact one-sided McNemar p ≤ 0.05, every non-cold open run `recovered_open`, mechanism shown in each), `supports_no_mechanism`, `inconclusive`. Arm B (`k1.b_outcome`): `headroom_weakened` if all 3 seeds `recovered_open`, `headroom_open` if any is cold, lost or partial, else `incomplete`. |
| **Prediction** | Gate: each closed burst run cold-backlogged ≈ 0.85; arm A starts ≈ 0.2. Given arm A runs: each open run cold ≈ 0.10, partial ≈ 0.03, recovered ≈ 0.87; mechanism shown ≈ 0.8. Outcomes: `supports` ≈ 0.40, `supports_no_mechanism` ≈ 0.10, `inconclusive` ≈ 0.49, `refutes` ≈ 0.01. Arm B: each seed cold ≈ 0.15; `headroom_weakened` ≈ 0.6. |
| **Decision under each outcome** | `supports`: K1 stated for this cell with its mechanism; arm B starts. `supports_no_mechanism`: K1's outcome stated without "held prefix" as shown; arm B starts. `refutes`: K1 reported as refuted at this cell and leaves the paper's core claims. `open_arm_overload`: K1 not testable there; the author decides. `inconclusive`: report; the author chooses between paired seeds 20+ and dropping K1 as a core claim. Arm B `headroom_open`: K1's wording states the headroom confound. |
| **Adversarial review** | One round with nine recommendations, among them a pattern bug that would have made every computation return `too_few`, a hit-rate readout that also measured the turn mix (replaced by prefix reuse), lost open runs counted as cold, and the paired McNemar test. All were applied before any run, except that the KV number 0.9 was kept (stated as a different statistic) and the different pre-burst state between arms was stated as an alternative. |
| **Result** | Arm A (reported 2026-11-15): `supports`; k_closed 5, k_open 0, n 5, exact one-sided McNemar p = 0.03125 (Fisher 0.00397), mechanism shown in 5 of 5; open arm cold in 0 of 5 (upper bound 0.451); drift run cold-backlogged, agrees. Arm B: `headroom_weakened`; 3 of 3 `recovered_open` at λ = 2.5, cold in 0 of 3 (upper bound 0.632). |
| **Prediction held** | arm A: no (`supports` ≈ 0.40 against `inconclusive` ≈ 0.49); arm B: yes (likeliest outcome; `headroom_weakened` ≈ 0.6) |
| **Not separated** | Working set against held prefixes: at the end the closed arm had 218–320 sessions in service, the open arm 9–11 (11–13 at λ = 2.5), so a smaller working set alone is not ruled out. Headroom is weakened, not excluded (no closed-loop arm at 2.5; three seeds). |
| **Corrections** | 2026-11-18: arm A's result called `supports` "the single likeliest" registered outcome; `inconclusive` (≈ 0.49) was. The verdict is unchanged. |
| **In the paper** | §4.4, P24 and P23; §4, P58 (Table 2); §4.4, P70; App. D, P33 (calibration) |
| **Notes** | Arm A's seal was kept until arm B ran; no conditional control was due. Open-loop arms met a larger shock (131–238 outstanding at 2.0, 212–316 at 2.5) than the closed arm (43–64) and still recovered. |
