# REG-21: the token-work readings

*Registered 2026-11-13 · a reading of runs already made · claim K3 · result 2026-11-13*

| | |
|---|---|
| **Question** | In the cold, backlogged state after a burst (`k1.cold_backlogged`), does the engine prefill uncached prompt tokens at the rate of the saturated engine with caching off (J1), and is that rate the same at λ = 2.0 and 2.4 (J2)? r = uncached prompt tokens per second over W, divided by the mean over REG-8's five saturated cache-off runs. |
| **Runs** | Batch 1: the 13 closed-loop L1 burst runs at 350 W made before REG-19 (λ = 2.4: 6 runs; λ = 2.2: 2; λ = 2.0: 5); W = [1680, 2580) s ([1680, 5580) s for REG-15). Batch 2: REG-19's five burst runs at λ = 2.0, seeds 15–19, W = [1680, 4080) s. 0 GPU h. |
| **Outcome rule** | `k3w.judge`. A run is judged if cold-backlogged and, in W, all-miss (reuse of later turns ≤ 0.05) and busy (at least one request waiting in ≥ 0.99 of scrapes, gauge covering W). J2 (batch 1): inside if the medians of r of the load groups with at least 3 judged runs differ by at most 0.05; undefined if fewer than 2 such groups. J1: inside if \|median of r − 1\| ≤ 0.05; undefined if fewer than 3 judged runs. J1 pools the loads only if J2 is inside, and only the groups J2 judged; otherwise `not_pooled`, J1 per group. A value at 0.05 is inside. |
| **Prediction** | Batch 1: each run judged ≈ 0.92; P(J2 undefined) ≈ 0.01 or less; P(J2 inside) ≈ 0.86; P(J2 outside) ≈ 0.13; slope of r on load ≈ +0.05 to +0.10 per req/s; λ = 2.0 inside ≈ 0.9 or more; λ = 2.4 inside ≈ 0.05. Batch 2: P(never computed) ≈ 0.4; P(J1 undefined) ≈ 0.24 with five runs; otherwise inside ≈ 0.65, outside high ≈ 0.3, outside low ≈ 0.05. |
| **Decision under each outcome** | Computing and reporting only, with wording ceilings. J1 inside (pooled only when every judged group agrees): "did the token work of the cache-off sweep within 0.05". J2 outside with a group outside: "one work rate at the two loads is not shown (load or day)", the outcome that would change K3's claim. J1 outside high: "r times the token work of the cache-off sweep". Batch 2, labelled retrospective by design, is reported beside batch 1 and never governs; batch 1 does not become the paper's statement. |
| **Adversarial review** | Nineteen rounds of adversarial review on drafts 3 to 26, each NOT READY, with separate approval passes; ended by a review-stop rule fixed before any batch existed (batch 2 labelled retrospective by design), and every item of the last round was applied before batch 1 was computed (draft 27). |
| **Result** | Batch 1: all 13 judged; J2 inside (spread 0.0005); J1 inside, pooled median r 1.021 over 11 runs (range 1.015 to 1.032); 1.021 at λ = 2.0 (n 5) and 1.020 at λ = 2.4 (n 6); slope of r on the load +0.0008 per req/s. Batch 2: J1 inside with no side, median r 1.028 (n 5, range 1.023 to 1.029, window 2400 s); fixed-load contrast with batch 1's λ = 2.0 group +0.0065. |
| **Prediction held** | yes (likeliest outcome) for batch 1's J2 (inside ≈ 0.86) and batch 2's J1 (inside ≈ 0.49 given five runs, DERIVED in the result); within batch 1, λ = 2.4 inside had ≈ 0.05 and the predicted slope (+0.05 to +0.10) was missed |
| **Not separated** | Load and day coincide in batch 1, so J2 reads "load or day"; a cancellation between dev mode or the day and redone prefill is not separated; for batch 2, J1 inside follows from the preconditions for any saturated all-miss engine with the same per-token prefill cost, and r restates completion rates already published. |
| **In the paper** | §4.3, P29 (batch 2); App. D, P30 (batch 1) and P32; §4.3, P57 (a later readout against E1's runs) |
| **Notes** | Both batches are retrospective: batch 1's tolerances were fixed knowing its runs' published numbers, and batch 2 is labelled retrospective by design because a script had most likely printed seed 17's end-of-run request counts before the thresholds were committed. The registration judges only r and departs from the author's earlier choices (a primary served-mix test, a per-run simulation); none of K3's four listed quantities is judged. |
