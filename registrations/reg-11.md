# REG-11

*Registered 2026-11-09 · GPU runs · result 2026-11-09*

| | |
|---|---|
| **Question** | With closed-loop turns (a session's later turn released at the previous turn's end plus its planned gap) and everything else as in REG-10, does a 180 s burst at λ = 2.4 leave the L1 server at 350 W holding a cold backlog while the same-seed control is healthy? Exploratory. |
| **Runs** | One pair at 350 W, seed 1, λ = 2.4, 2580 s, closed-loop turns (session starts and burst requests open loop), `loadgen_force_close`, dev mode: control `20261109-034255_stage2_control_l1pl350cl_r2.4` and burst run `20261109-042828_burst_l1pl350cl_r2.4_s1`. |
| **Outcome rule** | `gate.reg11_gate` = `gate.reg10_gate(REG11)`, REG-10's labels (`pass`, `drains`, `control_not_healthy`, `stuck_unconfirmed`, `inconclusive`). `shock_comparable` (read only under `drains`): both the session requests outstanding at the burst's end and the post-burst backlogged time ≥ 0.5 × REG-10's (reference 267 and 393.0 s, so ≥ 134 outstanding and ≥ 196.5 s). Readouts: `gate.release_delay`, `gate.shock_size`, `gate.turn0_share`, `gate.unreleased`; percent fast stays binned by planned time, latency measured from release. |
| **Prediction** | Both runs valid p ≈ 0.85; the burst fills the pool p ≈ 0.9; control `recovered` p ≈ 0.85. Given a valid pair: `pass` ≈ 0.15, `drains` ≈ 0.55, `control_not_healthy` ≈ 0.1, `stuck_unconfirmed` ≈ 0.1, `inconclusive` ≈ 0.1. Post-burst `secondary_cb` point ≈ 2.8. `shock_comparable` p ≈ 0.35. |
| **Decision under each outcome** | `pass`: report `turn0_share` against REG-10's spans and draft REG-12, the confirmatory matrix with closed-loop turns at λ = 2.4 (burst seeds 2–5, each with a same-seed control; ≥ 3 of 5), this pair not counted. `drains` with `shock_comparable`: open-loop overlap was not what kept L1 out of a stuck state; the author picks the next factor or writes L1 at 2.4 up as negative. `drains` without it: 'closed loop weakened the shock'. `control_not_healthy`: no closed-loop stuck attempt before a closed-loop cache-on sweep. `stuck_unconfirmed`: not rerun. `inconclusive`: rerun at most twice. |
| **Adversarial review** | One round of adversarial review: three blocking recommendations (a shock-size readout with a fixed comparability rule, a harness fix for a chain after an HTTP error, a check that every unsent later turn is explained) and four others (binning stated, `queued_miss_share` against the release time, a pre-burst release-delay baseline, `turn0_share`). All seven adopted before approval and the runs; the static λp was kept. |
| **Result** | `pass`: all three spans hold. Control `recovered`, burst run `stuck`. Spans: c 1.717, 1.790, 1.773 (c_upper 1.901, 1.978, 1.961) against λp 2.150, 2.677, 2.350; sessions' hit share 0.000 against baseline 0.828; KV 0.950–0.951; waiting mean 169.4, 200.3, 247.7. `secondary_cb` `not_sustainable`: c_b 1.793 over 1499 s (2687 completions). `shock_comparable` false (65 outstanding, 1499 s backlogged). `turn0_share` 0.155, 0.179, 0.148 against REG-10's 0.122, 0.124, 0.126. |
| **Prediction held** | no (`pass` had prior ≈ 0.15 against ≈ 0.55 for `drains`) |
| **Not separated** | A slow drain against a stuck state (the queue grows across the spans; a 4500 s watch separates them); queueing against eviction as the cause of the lost hits (needs C2's controls); preemption recompute as part of the loop or a separate cost. |
| **Corrections** | 2026-11-09: the `pass` branch's 'burst seeds 2–5 … ≥ 3 of 5' names four seeds, not five; REG-12 states its seeds explicitly (2–6). |
| **In the paper** | §4.4 (P11, the λ = 2.4 pair; text in Appendix C.7); one seed. Its prior is among those counted in Appendix D.2's calibration (P33). |
| **Notes** | Exploratory, one seed; the closed-loop release of later turns was a deviation from open-loop arrivals approved by the author for these runs only. The registration fixes comparability at ≥ 134 outstanding; the result states the threshold as 133.5. Later results qualify this `pass`: REG-12's controls at 2.4 did not stay healthy, and REG-13's registered decision reads REG-11's `pass` as not evidence of a metastable state. |
